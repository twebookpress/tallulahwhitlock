# Tallulah Whitlock Author Website

GitHub Pages-ready author website for Tallulah Whitlock.

Pages:
- `index.html` — homepage / newest release
- `books.html` — published books
- `book-love-lies-and-latte-foam.html` — Love, Lies and Latte Foam detail page
- `driftwood.html` — Driftwood & Co. Vacations series page
- `book-beach-house-rules.html` — Beach House Rules detail page
- `style.css` — site design
- `images/` — book covers

The site is intentionally static and free to host with GitHub Pages. Published books use direct Amazon links. The Amazon author page is used for reader follows and new-book notifications.
