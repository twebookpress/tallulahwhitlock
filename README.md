# Tallulah Whitlock Author Website

This is a GitHub Pages-ready starter site for Tallulah Whitlock.

## Files

- `index.html` — homepage
- `style.css` — site design
- `images/love-lies-and-latte-foam.jpg` — current book cover

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `tallulah-whitlock`.
2. Upload these files and folders.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the website address.

## Before publishing

Replace:
- `YOUR-EMAIL-HERE` with the newsletter/contact destination you want to use.
- The placeholder book description with your final blurb.
- Any future social media links.

The Amazon book button currently points to the Love, Lies and Latte Foam listing.
